Este aplicativo usa os seguintes projetos abertos, distribuídos sob Apache License 2.0:

- AndroidX Activity, CameraX, ExifInterface e Jetpack Media3 — The Android Open Source Project / Google, https://android.googlesource.com/platform/frameworks/support/ e https://github.com/androidx/media

- Dependências transitivas dos pacotes AndroidX (incluindo Guava ListenableFuture e Kotlin standard library, Apache 2.0), conforme metadados dos artefatos Maven originais.
